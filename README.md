
# Yadav Salon Management System

**Developer:** Shivam Birat Yadav  
**Course:** EGN 475 – Software Prototyping  
**University:** Atlantis University

## Project Overview
This project is a basic web application developed using Python and Flask. It demonstrates web routing and simple page navigation for a salon management system.

## Features
- Home page with salon introduction
- About page with salon information
- Navigation between pages

## Technologies
- Python 3.12
- Flask
- Visual Studio Code
- Git and GitHub

## How to Run
1. Install Python.
2. Install Flask using `python -m pip install flask`.
3. Run `python app.py`.
4. Open http://127.0.0.1:5000 in your browser.
