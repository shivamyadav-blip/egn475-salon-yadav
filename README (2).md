# Bella Vista Salon — Appointment Booking Prototype

**Course:** EGN 475: Software Prototyping  
**Student:** Shivam Birat Yadav  
**Option:** B — Bella Vista Salon (Coral Gables)

## Project choice
I chose Bella Vista Salon because appointment scheduling affects both clients and employees. This prototype focuses on reducing delays in responses to appointment requests through a simple web interface.

## Problem statement
Bella Vista Salon currently uses an existing online booking system, but clients may still need to wait for staff to respond to appointment requests. This causes uncertainty and inconvenience for clients and creates extra follow-up work for salon staff. Our prototype will allow clients to browse haircuts, coloring, and styling services, request available appointment times, and view appointment status while staff manage requests in one place, so that booking is faster, easier, and more organized.

## Target users
**Sofia Martinez — Client:** Wants to choose a service and time easily and know whether her request has been confirmed. She dislikes waiting for staff responses and is comfortable using websites. “I want to book my haircut without having to wait for someone to message me back.”

**Daniel Rivera — Salon receptionist:** Wants to review appointment requests, avoid conflicts, and update statuses from one interface. He dislikes repeated follow-ups and is moderately comfortable with scheduling software. “I need one clear calendar so I can confirm bookings quickly while helping customers at the front desk.”

## Must-have features
1. View a list of haircut, coloring, and styling services.
2. See a service description and estimated duration.
3. Select a service, date, and time to request an appointment.
4. Validate required booking details before submission.
5. Show clients their appointment requests and statuses.
6. Provide a staff calendar or appointment board.
7. Allow staff to confirm, complete, or cancel appointments.
8. Allow staff to add or edit available salon services.

## Not in this prototype
1. Online payments or deposits.
2. SMS or email reminders.
3. A native iOS or Android mobile app.
4. Loyalty points, coupons, or referral rewards.
5. Integration with the salon’s existing booking provider.
6. Automated staff assignment or advanced resource optimization.

## Prototype boundary
This is a classroom prototype, not a live booking system. Availability and appointment status will be demonstrated within the prototype; integration with the salon's existing booking provider is excluded.
